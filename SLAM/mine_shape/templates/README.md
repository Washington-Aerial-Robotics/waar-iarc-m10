# PFM-1 shape template (required for classical detector)

Place a **binary silhouette** of the PFM-1 mine here:

- **Filename:** `pfm1_silhouette.png`
- **Content:** White mine outline on black background (winged / asymmetric top or side view per your camera angle)
- **Source:** Trace from IARC Resource Addendum PFM-1 diagram; do not use a circular disc template.

Until this file exists, `ShapeMineDetector` returns no candidates (AprilTag path still works).
